### How to Be Listed

If you've contributed to this project, you should be listed here! Contributors are added:

1. **Automatically**: For code contributions via pull requests
2. **Manually**: Request to be added by opening an issue
3. **By maintainers**: Significant contributions will be acknowledged

### Types of Contributions

We recognize all types of contributions:

- 💻 **Code**: Bug fixes, features, refactoring
- 📖 **Documentation**: README, guides, tutorials, API docs
- 🎨 **Design**: UI/UX, graphics, diagrams
- 🐛 **Bug Reports**: Well-documented bug reports
- 💡 **Ideas**: Feature suggestions and improvements
- 🔍 **Review**: Code review and testing
- 📢 **Outreach**: Talks, blog posts, tutorials
- 🌍 **Translation**: Internationalization
- ❓ **Support**: Helping others in issues/discussions
